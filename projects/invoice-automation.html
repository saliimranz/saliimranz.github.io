AI Invoice Automation

Apr 2026 — Present Independent / Freelance
n8nOpenAIOCRGoogle SheetsGoogle Drive API

Businesses receiving daily invoices wasted hours on manual data entry — reading PDFs, retyping fields, running formulas. I built an 11-node n8n pipeline: Drive monitors a folder → file detected → OCR + LLM extracts all fields (vendor, line items, taxes, totals, IBAN) → auto-populates Google Sheets → archives file → sends notification. Zero human touch.

Impact

  • 80% faster processing per invoice
  • 50% reduction in AP team effort
  • 4× throughput increase
  • <4 seconds average runtime per invoice
  • Eliminated daily manual data-entry that previously consumed hours of finance-team time

AI Leverage

OCR extracts text from variable PDF layouts. LLM does structured field extraction — vendor, line items, taxes, totals, IBAN — with confidence scoring on each field. n8n orchestrates 11 nodes covering Drive folder watch, OCR, LLM extraction, Google Sheets population, archival, and Slack/email notification.

Cost-aware design: caches vendor-specific extraction patterns so the LLM only fires on novel layouts. Recurring vendors get processed nearly free after the first encounter.

Problems Faced

Variable PDF formats from different vendors broke fixed-template OCR. The OCR + LLM combo solved it for 95%+ of invoices by letting the model interpret semi-structured text.

Edge cases — missing fields, low-quality scans, non-standard tables — needed graceful fallbacks. Built a human-review queue for sub-threshold confidence so nothing silently fails.

Cost optimization at scale required caching extracted patterns per vendor. Without it, repetitive layouts would re-burn LLM tokens on every run.
